# RakibTech Excel Sales Analysis

## Project Overview

**RakibTech Excel Sales Analysis** is a professional Excel-based sales and financial analysis project developed for a fictional electronics retail and e-commerce business, **RakibTech Solutions**.

The project uses 2025 business data to analyze sales performance, profitability, expenses, customer behavior, regional performance, and sales channels. Microsoft Excel is used to clean, analyze, visualize, and present the data through an interactive dashboard and analytical reports.

## Business Objectives

The main objectives of this project are to:

- Analyze overall sales and profitability
- Identify monthly sales trends
- Compare product categories and regions
- Analyze customer types and payment methods
- Compare online and store sales
- Analyze business expenses
- Create a professional management dashboard
- Support business decision-making using data
